# Modeling-Human-Inference
Codes and data used in "Human inference reflects a normative balance of complexity and accuracy" by Tavoni, Doi, Pizzica, Balasubramanian, Gold (2022).

Python subject-level and trial-level exports, refitted models, and validation are
documented in [python/README.md](python/README.md). Open
[Python_Analysis.ipynb](Python_Analysis.ipynb) to load the dataframes and view
example behavior/model plots. Generated data are in `outputs/`.
